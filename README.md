# 📬 流年函匣 · Time-Capsule Mailbox

一个写给自己、写给TA、写给笔下那个人的复古信匣。

跑完一段剧情，心里总有些话想说——
对酒馆里陪你走了几百楼的那个角色，
对自己笔下的OC，对脑内反复走戏的自推——
那些来不及在剧情里说完的话，留下来的回忆，擦肩而过的瞬间，
都可以装进这个函匣里。

---

## 🗝️ 这是什么

一个**纯前端、无后端、离线可用**的网页应用，打开就能用，所有数据都存在自己浏览器里。
做成复古信纸风（泛黄纸页 + 手写字体 + 火漆封印 + 老照片），适合用来做：

* **酒馆角色存档**：RP 完给 TA 写一封信，把来不及说的话写下来
* **OC / 自推资料库**：给自己笔下的人物一个安身之处，不用再翻十几个 txt
* **回忆录 / 纪年册**：羁绊时间轴，重要节点打火漆封印
* **书信往来收藏**：你写的 + TA 的回信，一封封封存
* **跨次元收件箱**：任何你想寄信、但寄不出去的对象，都可以在这里

**核心是三件事：留住人、留住信、留住时间线。**

---

## 🚀 怎么用

### 安装

不用安装。
把 HTML 文件保存到本地，双击用浏览器打开即可。
也可以加到手机桌面当 PWA 用（安卓/iOS 的"添加到主屏幕"），像个独立 app。

### 数据存在哪

全部存在浏览器的 `localStorage` 里，**不上传、不联网、不经过任何服务器**。
换设备 / 清缓存前记得在「时光工坊 → 记忆管理」里**导出备份**（JSON 文件），换设备后再导入回来就行。

## 📖 四个标签页

点进任何一个角色，会看到四个标签页，左右滑动切换：

### 🖼️ 旧影
角色的基础资料页。
* 主照片（拍立得风格）+ 你的叠影照（可选，压在右下角）
* 缘起日期 / 相识天数（自动计算）
* 印象标签 / 心语寄辞
* 右上角「流年珍藏」小印章

基本上就是**这个角色的"档案封面"**。

### ✉️ 寄思
**你写给 TA 的信。**
RP 完意犹未尽？剧情跑到某个节点想停下来说句话？都写在这里。
* 支持 Markdown 语法：`**加粗**`、`*斜体*`、`---` 分隔线
* `"双引号里的内容"` 会自动变成斜体对话样式
* 可以装潢信纸（见下方"时光工坊"）
* 支持**保存为长图**导出分享

### 📜 回响
**TA 写给你的信。**
和"寄思"长得一样，但专门收 TA 的回信——可以是你让模型续写的、可以是从聊天记录里摘出来再润色的、也可以是自己脑补的。
分开两个标签是为了看起来更像真的在通信，而不是独白。

### 🕰️ 纪年
**羁绊时间轴。**
记录和这个角色一路走来的重要节点。

**格式很简单：**
```
# 阶段标题（比如：初遇期 / 暧昧期 / 恋爱中）
2024.03.15-初遇-那天下着雨
*2024.06.20-表白-他说了那句话
2024.09.01-搬家-开始一起生活
```

* 前面加 `*` 的节点会被打上**火漆封印**，标红高亮
* 每个节点可以点进去写"详细描述"（长文）、配插图
* 支持批量编辑，也支持单条添笔
* 自动按日期排序

## 🎨 时光工坊

从首页右上角的画笔图标进入，全局自定义区。

### 信纸装潢
* **底纹**：换信纸背景图（贴 URL 即可）
* **笔触**：字体（手写草书 / 衬线 / 楷体 / 自定义字体）
* **墨水颜色 / 字号 / 边际留白**：实时预览
* **预设模板库**：存好的方案一键切换，支持每个标签页用不同信纸——"寄思"用温柔米色纸，"回响"用冷淡蓝灰纸，自己玩

### 界面修饰
* 全局字体 / 文字色 / 背景色
* 内置五套配色：流年故里 / 竹影青瓷 / 胭脂旧梦 / 月半小夜 / 杏帘在望
* 支持自存方案

### 字体库
* 贴字体文件 URL 就能导入自定义字体
* 导入后在"信纸装潢"和"界面修饰"的字体下拉里能选到
* 想用什么手写体都行（记得字体源允许跨域）

### 记忆管理
* **导出备份** → JSON 文件存下来
* **恢复数据** → 导入之前的备份

**换设备、清缓存之前一定要导出！** 浏览器存储没备份就是没了。

## 🎵 彩蛋功能

### BGM
每个角色可以配一首 BGM（贴音频 URL）。
进入 TA 的详情页后，右上角会出现一个**转动的黑胶唱片**按钮，点一下开始放，自带氛围。
适合给每个角色配一首主题曲。

---

## 💡 使用小建议

* **一个角色一首 BGM**：进 TA 的页面自动有氛围，沉浸感拉满
* **"寄思"和"回响"用不同信纸**：视觉上区分"我写的"和"TA 写的"
* **纪年里多用火漆封印**：重要节点打星号，以后翻的时候一眼就能看到关键时刻
* **定期导出备份**：养成习惯，每周导一次 JSON，防止意外
* **给自推做时间轴**：不只是 RP，写小说做设定集也很好用
* **一份文件 = 一个世界**：想给不同系列 / 不同圈的角色分开存？复制几份 HTML，每份存不同浏览器配置文件就行
